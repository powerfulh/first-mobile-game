# 개인정보 처리방침

본 문서는 모바일 게임 **"전직 타워 디펜스"** (이하 "본 앱")의 개인정보 처리방침을 안내합니다.

최종 갱신일: 2026년 5월 16일

## 1. 수집하는 정보

본 앱은 사용자의 어떠한 개인정보도 수집·저장·전송하지 않습니다.

- 사용자 계정 / 로그인 기능 없음
- 광고 / 분석 SDK 사용 없음
- 서버와의 통신 없음 (완전 오프라인 동작)
- 카메라·위치·연락처·마이크 등 기기 권한 요청 없음

## 2. 로컬 저장 정보

게임 진행 상황(웨이브 / 골드 / 배치된 타워 / 일회성 안내 표시 여부 등)은 사용자 기기 내부의 **로컬 저장소(localStorage)** 에만 보관됩니다.

- 외부 서버로 전송되지 않습니다
- 다른 앱이나 사용자와 공유되지 않습니다
- 앱 삭제 또는 기기 설정 → 앱 → 저장공간 → 데이터 삭제로 완전히 제거 가능합니다

## 3. 권한

본 앱은 다음 권한만 선언합니다:

- **인터넷 (INTERNET)**: 안드로이드 WebView 기반 앱의 표준 매니페스트 권한. 본 앱은 실제 네트워크 통신을 수행하지 않습니다.

## 4. 어린이 개인정보

본 앱은 어떠한 사용자 정보도 수집하지 않으므로, 어린이 사용자가 사용해도 개인정보 노출 위험이 없습니다.

## 5. 변경사항

본 처리방침은 향후 앱 업데이트로 데이터 처리 방식이 변경될 경우 사전 공지 후 갱신됩니다.
