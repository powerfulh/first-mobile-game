# 웨이브 마일스톤

## 매 웨이브 변동 요소

| 항목 | 시작값 (Wave 1) | 변화 공식 |
|---|---|---|
| 적 수 | 8 | Wave 2~39: +2 / wave, Wave 40~79: +1 / wave, Wave 80+: 고정 |
| 지상 HP | 2 | `2 + floor(min(wave-1,9) × 0.4 + max(0,wave-10) × 0.6 + extraSlope)` (1~10웨이브 +0.4/wave, 이후 +0.6/wave; extraSlope는 50웨이브마다 +0.1) |
| 이동 속도 | 50 | +2 / wave (Wave 100+: 고정 248) |

## 단계별 메커니즘 변경점

### Wave 1 ~ 10: 점진적 가속 (맵5 고유)
- 스폰 간격 **0.8초 → 0.5초** (단계당 -0.034, Wave 10에서 캡 도달)
- 맵1(1.2초 시작, -0.08/wave)·맵3/맵4(0.95초 시작, -0.05/wave)보다 조밀하게 출발, 같은 Wave 10에 캡 합류
- 단순한 적 수 / HP / 속도 증가만

### Wave 6 ~: 공중 적 등장
- 출현 확률: `(wave - 5) × 2%`
- 공중 HP는 지상의 0.6배 (이 시점)
- 50% 상한 도달은 **Wave 30**

### Wave 11 ~: RNG 조밀도 시작
- 베이스 0.5초에 매 웨이브 RNG narrow factor 적용 → 0.2~0.5초 변동
- 임계 직후엔 변동폭이 좁고 점진적으로 넓어짐
- **Wave 11 → Wave 30**에 걸쳐 풀 RNG 범위(0.4~1.0 narrow)에 도달
- Wave 31 ~ 100: narrow 0.40 ~ 1.00 고정 (다음 변경은 Wave 101)

### Wave 31 ~: 공중 HP 강화 시작
- 공중 HP 비율 0.6 → 1.0 점진 증가 (`+0.02/wave`)
- **Wave 50**에 지상과 동률(1.0) 도달

### Wave 40 ~: 적 수 증가량 완화
- 단계당 +2 → **+1**

### Wave 51 ~: 방어막 적 등장
- 출현 확률 범위: **1% ~ 20%**. 그 웨이브의 narrow RNG 범위 기준 정규화 매핑 — 후반에 narrow 상하한이 좁아져도 그 웨이브의 sparse일 때 상한 도달
  - 그 웨이브 narrow 상한 (sparse) → 출현 확률 상한
  - 그 웨이브 narrow 하한 (dense) → 1%
- 상한 20%는 Wave 80까지 유지 (이후 확장은 웨이브 순서의 각 섹션 참고)
- 보스는 적용 안 됨

### Wave 51 ~ 70: 방어막 데미지 감소 상승
- Wave 51 **-1.1**에서 매 웨이브 +0.1 → **Wave 70에 -3.0 도달 후 고정**
- Wave 130~145에서 추가 강화 (별도 섹션)

### Wave 80 ~: 적 수 고정
- 단계당 +1 → **0** (증가 중단, Wave 79의 124마리로 영구 고정)

### Wave 81 ~ 90: 방어막 확률 상한 확장
- 매 웨이브 상한 +2% (10 웨이브 누적 +20%)
  - Wave 90: 상한 40% 도달
- Wave 91~100: 상한 40% 고정

### Wave 100 ~: 이동 속도 고정
- Wave 100의 속도값 248로 영구 고정 (`50 + 99 × 2`)

### Wave 101 ~ 110: 조밀도 하한 추가 강화 + 방어막 확률 상한 추가 확장
- 조밀도: 매 웨이브 minNarrow를 -0.01씩 감소 (10 웨이브 동안 누적 -0.10)
  - Wave 110: minNarrow = 0.40 - 0.10 = 0.30 (최소 spawnInterval 0.5 × 0.30 = 0.15s)
- 방어막 확률 상한: 매 웨이브 +1%씩 추가 확장 (10 웨이브 동안 누적 +10%)
  - Wave 110: 상한 50% 도달
- Wave 111 ~ 120: narrow 0.30 ~ 1.00 고정 (다음 조밀도 변경은 Wave 121)
- Wave 111+: 방어막 상한 50% 고정

### Wave 111 ~ 130: 재생 적 등장
- 출현 확률: Wave 111 0.2%부터 매 웨이브 +0.2%, Wave 130에서 상한 4.0% 도달
- Wave 131+: 출현 확률 4.0% 고정
- 이동 속도: 일반의 50%
- HP: 일반 지상과 동일
- 자가 회복: HP < 100%일 때 `hpMax × 12% / 초` 회복
- 보스에는 적용 안 됨

### Wave 121 ~ 130: 조밀도 상한 추가 강화 (maxNarrow 감소)
- 매 웨이브 maxNarrow를 -0.01씩 (10 웨이브 동안 누적 -0.10)
  - Wave 130: maxNarrow = 1.00 - 0.10 = 0.90
- Wave 131 ~ 170: narrow 0.30 ~ 0.90 고정 (다음 변경은 Wave 171)
- 효과: spawnInterval RNG 상한(가장 느슨한 분포)이 낮아져 평균 스폰 빈도 추가 상승

### Wave 130 ~ 145: 방어막 데미지 감소 강화
- 매 웨이브 방어막 적의 데미지 감소량 +0.1 (15 웨이브 동안 누적 +1.5)
  - Wave 131: -3.1 → Wave 145: -4.5
- Wave 146+: -4.5 고정

### Wave 151 ~ 160: 장벽 적 등장
- 출현 확률: Wave 151 0.4%부터 매 웨이브 +0.4%, Wave 160에서 상한 4.0% 도달
- Wave 161+: 출현 확률 4.0% 고정
- 공중 타입, HP/속도는 일반 적과 동일
- 처치 시 그 자리에 반경 60 장벽 생성 (HP는 일반 적의 2배)
  - 파괴되거나 웨이브 종료까지 유지
  - HP 비율 기준 3단계 외관 (>66% 견고 / >33% 손상 / 그 외 부서지기 직전)
- 장벽은 공중 공격 화력을 대신 받음 (단일 타워는 조준은 정상, 발사된 빔/투사체가 장벽에 막힘)
- 트랩/래이다르의 areaSweep은 장벽 안 적 보호, 장벽 자체는 데미지
- 지상 전용 공격은 장벽 영향 없음 (그대로 통과)

### Wave 161 ~ 170: 재생 적 회복률 강화
- 매 웨이브 회복률 +1% (10 웨이브 누적 +10%)
  - Wave 161: 13% → Wave 170: 22%
- Wave 171+: 22% 고정

### Wave 171 ~ 180: 조밀도 상하한 추가 강화 + 장벽 적 확률 상향
- 매 웨이브 minNarrow / maxNarrow 각각 -0.01 (10 웨이브 누적 -0.10)
  - Wave 180: minNarrow 0.20 / maxNarrow 0.80
- 매 웨이브 장벽 적 출현 확률 +0.4% (누적 +4.0%)
  - Wave 180: 8.0%
- Wave 181+: 모두 고정 (minNarrow 0.20 / maxNarrow 0.80 / 장벽 8.0%)

### Wave 181 ~ 190: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +3% (10 웨이브 누적 +30%)
  - Wave 181: 53% → Wave 190: 80%
- Wave 191+: 80% 고정

### Wave 191 ~ 200: 재생 적 강화
- 매 웨이브 회복률 +1% (Wave 191: 23% → Wave 200: 32%)
- 매 웨이브 출현 확률 +0.4% (Wave 191: 4.4% → Wave 200: 8.0%)
- Wave 201+: 회복률 32% / 출현 확률 8% 고정

### Wave 50, 100, 150, 200: HP 슬로프 단계 상승
- 50웨이브 단위로 HP 증가량 +0.1
- Wave 50: 0.6 → **0.7**
- Wave 100: 0.7 → **0.8**
- Wave 150: 0.8 → **0.9**
- Wave 200+: 0.9 → **1.0** (최종 상한, 50웨이브당 HP +50)

## 보너스 메커니즘 (웨이브 종료 시)

- 모든 전직 가능 타워에 **+1 XP** (자동)
- 사거리 내에 배이스 / 비콘 / 데몬이 있으면 **+5 XP (5배 보너스, 고정값)**
- 다중 버프 소스 겹쳐도 5배 이상 누적되지 않음

## 난이도 곡선 의도

- **초반 (1~9)**: 해금 맵이라 학습보다는 실전 — 시작 스폰 간격 0.8초로 전 맵 중 가장 조밀하게 출발해 초반부터 배치 템포를 압박.
- **중반 (10~29)**: RNG 조밀도 + 공중 비중 증가로 다양성 확보. Tier 2 전직 압박.
- **후반 (30~50)**: 공중 HP 상승으로 대공 화력의 가치 증가. Tier 3 진입 시기.
- **종반 (50+)**: HP 슬로프 단계적 상승. 50웨이브 간격으로 규모 한 단계씩 확장 → 200까지 도달이 목표.
- **변곡점 (111~130)**: 재생 적 등장. 단발 화력의 한계가 노출되어 광역·관통·마킹 카운터(4티어 합체 포함)의 가치가 부각됨.
- **변곡점 (151~160)**: 장벽 적 등장. 공중 공격 화력이 장벽에 흡수됨 — 지상 전용 / areaSweep / 장벽 적 자체를 일점사로 처리하는 전략 필요.
- **안정구간 (200+)**: 모든 변수 상한. 적 수와 HP가 50웨이브당 일정량씩 증가하는 안정적 스케일.
