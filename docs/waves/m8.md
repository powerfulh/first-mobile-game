# 웨이브 마일스톤

맵8 "근원" — 지상 적이 전부 **EMP**로 대체된 맵. 재생·수송 적 미출현, 공중은 일반·치료·장벽 적. 경로에 공중 숏컷 3 + 지하도 2.

## 매 웨이브 변동 요소

| 항목 | 시작값 (Wave 1) | 변화 공식 |
|---|---|---|
| 적 수 | 8 | Wave 2~39: +2 / wave, Wave 40~79: +1 / wave, Wave 80+: 고정(124) |
| 지상 HP | 2 | `2 + floor(min(wave-1,9) × 0.4 + max(0,wave-10) × 0.6 + extraSlope)` (1~10웨이브 +0.4/wave, 이후 +0.6/wave; **extraSlope는 40웨이브마다 +0.1 — 40·80·120·160·200, 5단계**) |
| 이동 속도 | 50 | +2 / wave (Wave 100+: 고정 248) |

> 지상 적은 **EMP**라 실제 HP는 표기(지상 HP)의 **0.5배**. 공중 적은 표기 × 공중 HP 비율.

## 단계별 메커니즘 변경점

### Wave 1 ~ 10: 점진적 가속
- 스폰 간격 0.72초 → 0.5초 (단계당 -0.025, Wave 10에서 캡 도달) — 맵7과 함께 전 맵 최속
- **지상 적은 전부 EMP** (basicKind): 일반 적 대신 Wave 1부터 등장. HP는 지상 기준의 0.5배
  - 처치 시 사거리 내 타워가 있으면 그 자리에 **EMP 장치**로 변해 주변 타워를 스턴 — 지상 적이 전부 EMP라 경로 옆 타워는 상시 스턴 위험

### Wave 6 ~: 공중 적 등장
- 출현 확률: `(wave - 5) × 2%`
- 공중 HP는 지상의 0.6배 (이 시점)
- 50% 상한 도달은 **Wave 30**

### Wave 11 ~: RNG 조밀도 시작
- 베이스 0.5초에 매 웨이브 RNG narrow factor 적용 → 0.2~0.5초 변동
- **Wave 11 → Wave 30**에 걸쳐 풀 RNG 범위(0.4~1.0 narrow)에 도달

### Wave 21 ~ 30: 조밀도 하한 추가 강화
- 매 웨이브 minNarrow를 -0.01씩 감소 (10 웨이브 동안 누적 -0.10)
  - Wave 30: minNarrow = 0.40 - 0.10 = 0.30 (최소 spawnInterval 0.5 × 0.30 = 0.15s)
- RNG 램프(11~30)와 겹쳐, 두 감소량이 합산돼 초반부터 매우 조밀한 러시 형성
- Wave 31 ~ 60: narrow 0.30 ~ 1.00 고정 (다음 변경은 Wave 61)

### Wave 31 ~: 공중 HP 강화 시작
- 공중 HP 비율 0.6 → 1.0 점진 증가 (`+0.02/wave`)
- **Wave 50**에 지상과 동률(1.0) 도달

### Wave 40 ~: 적 수 증가량 완화
- 단계당 +2 → **+1**

### Wave 41 ~ 70: 충격 분산 적 등장
- 출현 확률: Wave 41 0.4%부터 매 웨이브 +0.4%, Wave 70에서 상한 12.0% 도달
- Wave 71+: 출현 확률 12.0% 고정
- 지상 타입, HP는 일반 지상의 75%
- 충격 분산 횟수 3 — 공격받으면 1을 소모해 그 피해를 0.1로 고정 (발동 시 방패 이펙트)
- 횟수가 3보다 적으면 0.5초마다 1씩 회복

### Wave 51 ~: 방어막 적 등장
- 출현 확률 범위: **1% ~ 40%** (shieldStartCap 0.4, 맵2와 동일). 그 웨이브의 narrow RNG 범위 기준 정규화 매핑
  - 그 웨이브 narrow 상한 (sparse) → 출현 확률 상한
  - 그 웨이브 narrow 하한 (dense) → 1%
- 상한 40%는 Wave 90까지 유지 (81~90 확장 없음 — 등장부터 40%)

### Wave 51 ~ 70: 방어막 데미지 감소 상승
- Wave 51 **-1.1**에서 매 웨이브 +0.1 → **Wave 70에 -3.0 도달 후 고정**
- Wave 130~145에서 추가 강화 (별도 섹션)

### Wave 61 ~ 70: 조밀도 상한 추가 강화 (maxNarrow 감소)
- 매 웨이브 maxNarrow를 -0.01씩 (10 웨이브 동안 누적 -0.10)
  - Wave 70: maxNarrow = 1.00 - 0.10 = 0.90
- Wave 71 ~ 100: narrow 0.30 ~ 0.90 고정 (다음 변경은 Wave 101)

### Wave 71 ~ 90: 치료 적 등장
- 출현 확률: Wave 71 0.4%부터 매 웨이브 +0.4%, Wave 90에서 상한 8.0% 도달
- Wave 91+: 출현 확률 8.0% 고정
- 공중 타입, 체력·속도는 일반 적과 동일
- 사거리 80 내 체력 90% 이하의 공중 타입(장벽 제외)에 락온해 제자리에 멈춰 치료
- 맵8은 재생 적이 없어 치료 대상은 공중 적(일반·장벽 제외)

### Wave 81 ~ 90: 치료 적 회복률 강화
- 매 웨이브 회복률 +1% (10 웨이브 누적 +10%)
  - Wave 81: 13% → Wave 90: 22%
- Wave 91+: 22% 고정 (맵8은 재생 없어 치료 적 회복률에만 적용)

### Wave 91 ~ 100: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +1% (10 웨이브 누적 +10%)
  - Wave 100: 상한 50% 도달
- Wave 101+: 방어막 상한 50% 고정 (다음 확장은 Wave 141)

### Wave 100 ~: 이동 속도 고정
- Wave 100의 속도값 248로 영구 고정 (`50 + 99 × 2`)

### Wave 101 ~ 110: 조밀도 상하한 추가 강화
- 매 웨이브 minNarrow / maxNarrow 각각 -0.01 (10 웨이브 누적 -0.10)
  - Wave 110: minNarrow 0.20 / maxNarrow 0.80 (조밀도 최종)
- Wave 111+: narrow 0.20 ~ 0.80 고정

### Wave 111 ~ 120: 치료 적 회복률 후반 강화
- 매 웨이브 회복률 +1% (Wave 111: 23% → Wave 120: 32%)
- Wave 121+: 회복률 32% 고정 (재생 출현 확률 강화 부분은 재생이 없어 무효)

### Wave 121 ~ 160: 장벽 적 등장
- 출현 확률: Wave 121 0.4%부터 매 웨이브 +0.4%, Wave 130에서 상한 4.0% 도달 → Wave 151~160 상향으로 **Wave 160에 8.0%**
- 공중 타입, HP/속도는 일반 적과 동일
- 처치 시 그 자리에 반경 60 장벽 생성 (HP는 일반 적의 2배)
  - 파괴되거나 웨이브 종료까지 유지, HP 비율 기준 3단계 외관
- 장벽은 공중 공격 화력을 대신 받음 (조준은 정상, 발사된 빔/투사체가 장벽에 막힘)
- 지상 전용 공격·areaSweep은 장벽 영향 없음(그대로 통과·데미지)

### Wave 130 ~ 145: 방어막 데미지 감소 강화
- 매 웨이브 방어막 적의 데미지 감소량 +0.1 (15 웨이브 동안 누적 +1.5)
  - Wave 131: -3.1 → Wave 145: -4.5
- Wave 146+: -4.5 고정

### Wave 141 ~ 150: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +3% (10 웨이브 누적 +30%)
  - Wave 150: 상한 80% 도달
- Wave 151+: 방어막 상한 80% 고정

### Wave 40, 80, 120, 160, 200: HP 슬로프 단계 상승
- 40웨이브 경계마다 HP 증가량 +0.1 (40웨이브 간격, **5단계** — 기본 맵의 50웨이브·4단계보다 1단계 많음)
- Wave 40: 0.6 → **0.7** / Wave 80: → **0.8** / Wave 120: → **0.9** / Wave 160: → **1.0** / Wave 200+: → **1.1** (최종, 기본 맵 1.0보다 가파름)

## 보너스 메커니즘 (웨이브 종료 시)

- 모든 전직 가능 타워에 **+1 XP** (자동)
- 사거리 내에 경험치 강화 타워가 있으면 **+5 XP (5배 보너스, 고정값)**
- 다중 버프 소스 겹쳐도 5배 이상 누적되지 않음

## 난이도 곡선 의도

- **초반 (1~10)**: 전 맵 최속 스폰(0.72초)에 **지상 적이 전부 EMP**. 시작 골드 150·무료 tier1 1기로 초기 여유는 있으나, 경로 옆 타워가 처음부터 EMP 스턴에 노출돼 — 배치 위치·가동률 관리가 맵의 핵심 축이 됨. 맵명 "근원"처럼 EMP가 상시 기저 위협.
- **조기 조밀 (21~30)**: 조밀도 하한 강화가 RNG 램프와 겹쳐 두 감소량이 합산 → 초중반부터 스폰이 극도로 조밀. 화력 처리량이 일찍 시험받음.
- **지상 압박 (41~70)**: 충격 분산 적(지상) 등장 — 피격마다 분산 횟수로 피해를 0.1로 흡수하고 회복. EMP와 함께 지상 처리를 까다롭게 해, 공속 빠른 다타격·광역으로 횟수를 소진시키는 전략 필요. 방어막 적(51~)도 등장부터 1~40%로 강함.
- **공중 지원 체계 (71~160)**: 치료 적(71~, 다친 공중 아군 회복)에 이어 장벽 적(121~, 공중 화력 흡수)이 등장. 숏컷 3개로 공중 유닛이 방어선을 앞질러 빠져나가고, 치료·장벽이 공중 적 생존을 늘림 — 공중 화력을 한곳에 몰아 조기 처치하는 것이 관건. 지하도 2개 구간에선 지상 EMP가 은신·조준 불가.
- **압축된 후반 (91~150)**: 방어막 상한(→50% @ 100, →80% @ 150)과 조밀도 최종(→110)이 앞당겨져, 표준 후반 난이도를 절반 시점에 몰아넣음.
- **가파른 HP 스케일**: HP 슬로프가 40웨이브 간격 5단계(최종 1.1/wave, 전 맵 최고)로 상승 → 후반 HP가 다른 맵보다 빠르게 무거워짐. 지상 EMP는 HP 절반이지만, 공중 적(치료·장벽 포함)은 이 슬로프를 그대로 받아 후반 대공 부담이 큼.
- **없는 변수**: 재생·수송 적 미출현.
- **안정구간 (200+)**: 모든 변수 상한. 적 수 124·HP가 50웨이브당 일정량씩(최종 슬로프 1.1/wave) 증가하는 안정적 스케일.
