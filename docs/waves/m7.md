# 웨이브 마일스톤

## 매 웨이브 변동 요소

| 항목 | 시작값 (Wave 1) | 변화 공식 |
|---|---|---|
| 적 수 | 8 | Wave 2~35: +2 / wave, Wave 36~79: +1 / wave, Wave 80+: 고정(120) |
| 지상 HP | 2 | `2 + floor(min(wave-1,9) × 0.4 + max(0,wave-10) × 0.6 + extraSlope)` (1~10웨이브 +0.4/wave, 이후 +0.6/wave; extraSlope는 50웨이브마다 +0.1) |
| 이동 속도 | 50 | +2 / wave (Wave 100+: 고정 248) |

## 단계별 메커니즘 변경점

### Wave 1 ~ 10: 점진적 가속
- 스폰 간격 0.72초 → 0.5초 (단계당 -0.025, Wave 10에서 캡 도달)
- 단순한 적 수 / HP / 속도 증가만

### Wave 6 ~: 공중 적 등장
- 출현 확률: `(wave - 5) × 2%`
- 공중 HP는 지상의 0.6배 (이 시점)
- 50% 상한 도달은 **Wave 30**

### Wave 11 ~: RNG 조밀도 시작
- 베이스 0.5초에 매 웨이브 RNG narrow factor 적용 → 0.2~0.5초 변동
- 임계 직후엔 변동폭이 좁고 점진적으로 넓어짐
- **Wave 11 → Wave 30**에 걸쳐 풀 RNG 범위(0.4~1.0 narrow)에 도달
- Wave 31 ~ 40: narrow 0.40 ~ 1.00 고정 (다음 변경은 Wave 41)

### Wave 21 ~ 40: 재생 적 등장
- 출현 확률: Wave 21 0.2%부터 매 웨이브 +0.2%, Wave 40에서 상한 4.0% 도달
- Wave 41+: 출현 확률 4.0% 고정
- 이동 속도: 일반의 50%
- HP: 일반 지상과 동일
- 자가 회복: HP < 100%일 때 `hpMax × 12% / 초` 회복

### Wave 31 ~ 40: 재생/치료 적 회복률 강화
- 매 웨이브 회복률 +1% (10 웨이브 누적 +10%)
  - Wave 31: 13% → Wave 40: 22%
- Wave 41+: 22% 고정

### Wave 31 ~: 공중 HP 강화 시작
- 공중 HP 비율 0.6 → 1.0 점진 증가 (`+0.02/wave`)
- **Wave 50**에 지상과 동률(1.0) 도달

### Wave 36 ~: 적 수 증가량 완화
- 단계당 +2 → **+1**

### Wave 41 ~ 50: 조밀도 하한 추가 강화
- 매 웨이브 minNarrow를 -0.01씩 감소 (10 웨이브 동안 누적 -0.10)
  - Wave 50: minNarrow = 0.40 - 0.10 = 0.30 (최소 spawnInterval 0.5 × 0.30 = 0.15s)
- Wave 51 ~ 60: narrow 0.30 ~ 1.00 고정 (다음 변경은 Wave 61)

### Wave 51 ~: 방어막 적 등장
- 출현 확률 범위: **1% ~ 20%**. 그 웨이브의 narrow RNG 범위 기준 정규화 매핑 — 후반에 narrow 상하한이 좁아져도 그 웨이브의 sparse일 때 상한 도달
  - 그 웨이브 narrow 상한 (sparse) → 출현 확률 상한
  - 그 웨이브 narrow 하한 (dense) → 1%
- 상한 20%는 Wave 70까지 유지 (이후 확장은 웨이브 순서의 각 섹션 참고)

### Wave 51 ~ 70: 방어막 데미지 감소 상승
- Wave 51 **-1.1**에서 매 웨이브 +0.1 → **Wave 70에 -3.0 도달 후 고정**
- Wave 130~145에서 추가 강화 (별도 섹션)

### Wave 61 ~ 70: 조밀도 상한 추가 강화 (maxNarrow 감소)
- 매 웨이브 maxNarrow를 -0.01씩 (10 웨이브 동안 누적 -0.10)
  - Wave 70: maxNarrow = 1.00 - 0.10 = 0.90
- Wave 71 ~ 90: narrow 0.30 ~ 0.90 고정 (다음 변경은 Wave 91)
- 효과: spawnInterval RNG 상한(가장 느슨한 분포)이 낮아져 평균 스폰 빈도 추가 상승

### Wave 71 ~ 80: 방어막 확률 상한 확장
- 매 웨이브 상한 +2% (10 웨이브 누적 +20%)
  - Wave 80: 상한 40% 도달

### Wave 81 ~ 90: 방어막 확률 상한 추가 확장
- 매 웨이브 +1%씩 추가 확장 (10 웨이브 동안 누적 +10%)
  - Wave 90: 상한 50% 도달
- Wave 91+: 방어막 상한 50% 고정

### Wave 80 ~: 적 수 고정
- 단계당 +1 → **0** (증가 중단, Wave 79의 120마리로 영구 고정)

### Wave 81 ~ 100: 수송 적 등장
- 출현 확률: Wave 81 0.8%부터 매 웨이브 +0.8%, Wave 100에서 상한 16.0% 도달
- Wave 101+: 출현 확률 16.0% 고정
- 공중 타입, 이동 속도는 일반 적의 **75%**
- 이동 중 최대 2회(경로 진행률 약 10%·20% 지점), 체력 40% 이상이면 체력 33%를 소모해 그 자리에 일반 적(체력 40%)을 투하
- 투하할 때마다 중앙의 빨간 원이 하나 사라짐 (남은 투하 횟수 표시)

### Wave 91 ~ 100: 조밀도 상하한 추가 강화
- 매 웨이브 minNarrow / maxNarrow 각각 -0.01 (10 웨이브 누적 -0.10)
  - Wave 100: minNarrow 0.20 / maxNarrow 0.80
- Wave 101+: 고정 (minNarrow 0.20 / maxNarrow 0.80)

### Wave 100 ~: 이동 속도 고정
- Wave 100의 속도값 248로 영구 고정 (`50 + 99 × 2`)

### Wave 101 ~ 110: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +3% (10 웨이브 누적 +30%)
  - Wave 101: 53% → Wave 110: 80%
- Wave 111+: 80% 고정

### Wave 130 ~ 145: 방어막 데미지 감소 강화
- 매 웨이브 방어막 적의 데미지 감소량 +0.1 (15 웨이브 동안 누적 +1.5)
  - Wave 131: -3.1 → Wave 145: -4.5
- Wave 146+: -4.5 고정

### Wave 141 ~ 160: 치료 적 등장
- 출현 확률: Wave 141 0.4%부터 매 웨이브 +0.4%, Wave 160에서 상한 8.0% 도달
- Wave 161+: 출현 확률 8.0% 고정
- 공중 타입, 체력·속도는 일반 적과 동일
- 사거리 80 내 체력 90% 이하의 공중 타입(장벽 제외)에 락온해 제자리에 멈춰 치료
- 회복률은 재생 적과 동일 기준

### Wave 171 ~ 180: 재생/치료 적 강화
- 매 웨이브 회복률 +1% (Wave 171: 23% → Wave 180: 32%) — 재생·치료 적 공통
- 매 웨이브 재생 적 출현 확률 +0.4% (Wave 171: 4.4% → Wave 180: 8.0%)
- Wave 181+: 회복률 32% / 재생 출현 확률 8% 고정

### Wave 50, 100, 150, 200: HP 슬로프 단계 상승
- 50웨이브 단위로 HP 증가량 +0.1
- Wave 50: 0.6 → **0.7**
- Wave 100: 0.7 → **0.8**
- Wave 150: 0.8 → **0.9**
- Wave 200+: 0.9 → **1.0** (최종 상한, 50웨이브당 HP +50)

## 보너스 메커니즘 (웨이브 종료 시)

- 모든 전직 가능 타워에 **+1 XP** (자동)
- 사거리 내에 경험치 강화 타워가 있으면 **+5 XP (5배 보너스, 고정값)**
- 다중 버프 소스 겹쳐도 5배 이상 누적되지 않음

## 난이도 곡선 의도

- **초반 (1~9)**: 전 맵 중 가장 조밀한 출발. 시작 스폰 간격 0.72초(맵5·6의 0.8초보다 빠름)에 시작 골드 100(최저 수준)·고정 타워 3기가 전부 고장 상태라, 학습 여유 없이 1웨이브부터 빠듯한 배치·경제 판단을 강요.
- **조기 회복 압박 (21~40)**: 재생 적이 Wave 21에 등장하고 31~40에 회복률이 12%→22%로 조기 강화. 재생이 111에 오는 맵1과 대조적으로, 낮은 티어 화력으로 회복을 뚫어야 하는 국면이 초중반에 앞당겨져 집중 화력·회복 차단의 가치가 일찍 부각.
- **중반 (10~50)**: RNG 조밀도·공중 비중·조기 재생이 겹치는 다변수 구간. 적 수 완화(36)·조밀도 하한 강화(41~50)도 앞당겨져 스폰 밀도가 빠르게 최대치에 근접. Tier 2~3 전직 압박 시기.
- **압축된 후반 (51~110)**: 방어막 등장(51) 이후 방어막 감소(51~70)·조밀도 상한(61~70)·방어막 상한 3단계 확장(71~110)·조밀도 상하한(91~100)이 전부 앞당겨져, 맵1 기준 180번대에 오는 최종 조밀도(narrow 0.20~0.80)와 방어막 상한(80%)에 **Wave 110에 이미 도달**. 표준 후반 난이도를 절반 시점에 몰아넣은 압축 곡선.
- **공중·이탈 집중 (81~160)**: 수송 적이 상한 16%(타 맵의 4배)로 쏟아지고, 경로 숏컷으로 공중 유닛이 방어선을 앞질러 빠져나감 — 맵명 "이탈"의 정체성. 치료 적(141~160)이 다친 공중 아군에 락온해 회복시켜 수송·공중 적의 생존을 늘리므로, 공중 화력을 한곳에 몰아 락온·투하 전에 처치하지 못하면 방어선 안쪽 누수가 누적. 공중 조기 처치가 최대 관건.
- **회복 정점 (171~180)**: 재생 회복률 32%·재생 출현 8%로 상승하고 치료 적 회복률도 동반 상승. 재생·치료 이중 회복이 겹쳐 지속·광역·마킹 화력 없이는 처치 속도가 회복에 잠식됨.
- **없는 변수**: 장벽·EMP·충격 분산 적 미출현. 위협을 공중(일반·수송·치료)과 재생/회복에 집중한 구성. 최종 적 수 120은 많지 않지만 빠른 템포·숏컷·회복 밀도로 체감 난도를 유지.
- **안정구간 (200+)**: 모든 변수 상한. HP 슬로프가 50웨이브마다 한 단계씩(0.6→1.0) 오르며 적 수·HP가 꾸준히 확장 — 200 돌파가 목표.
