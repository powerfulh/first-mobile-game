# 웨이브 마일스톤

## 매 웨이브 변동 요소

| 항목 | 시작값 (Wave 1) | 변화 공식 |
|---|---|---|
| 적 수 | 8 | Wave 2~39: +2 / wave, Wave 40~70: +1 / wave, Wave 71+: 고정 |
| 지상 HP | 2 | `2 + floor(min(wave-1,9) × 0.4 + max(0,wave-10) × 0.6 + extraSlope)` (1~10웨이브 +0.4/wave, 이후 +0.6/wave; extraSlope는 50웨이브마다 +0.1) |
| 이동 속도 | 50 | +2 / wave (Wave 100+: 고정 248) |

## 단계별 메커니즘 변경점

### Wave 1 ~ 10: 점진적 가속 (맵3 고유)
- 스폰 간격 **0.95초 → 0.5초** (단계당 -0.05, Wave 10에서 캡 도달)
- 맵1(1.2초 시작, -0.08/wave)보다 처음부터 조밀하게 출발, 같은 Wave 10에 캡 합류
- 단순한 적 수 / HP / 속도 증가만

### Wave 6 ~: 공중 적 등장
- 출현 확률: `(wave - 5) × 2%`
- 공중 HP는 지상의 0.6배 (이 시점)
- 50% 상한 도달은 **Wave 30**

### Wave 11 ~: RNG 조밀도 시작
- 베이스 0.5초에 매 웨이브 RNG narrow factor 적용 → 0.2~0.5초 변동
- 임계 직후엔 변동폭이 좁고 점진적으로 넓어짐
- **Wave 11 → Wave 30**에 걸쳐 풀 RNG 범위(0.4~1.0 narrow)에 도달
- Wave 31 ~ 40: narrow 0.40 ~ 1.00 고정 (다음 변경은 Wave 41)

### Wave 31 ~: 공중 HP 강화 시작
- 공중 HP 비율 0.6 → 1.0 점진 증가 (`+0.02/wave`)
- **Wave 50**에 지상과 동률(1.0) 도달

### Wave 40 ~: 적 수 증가량 완화
- 단계당 +2 → **+1**

### Wave 41 ~ 50: 조밀도 하한 추가 강화
- 매 웨이브 minNarrow를 -0.01씩 감소 (10 웨이브 동안 누적 -0.10)
  - Wave 50: minNarrow = 0.40 - 0.10 = 0.30 (최소 spawnInterval 0.5 × 0.30 = 0.15s)
- Wave 51 ~ 60: narrow 0.30 ~ 1.00 고정 (다음 조밀도 변경은 Wave 61)

### Wave 51 ~: 방어막 적 등장
- 출현 확률 범위: **1% ~ 20%**. 그 웨이브의 narrow RNG 범위 기준 정규화 매핑 — 후반에 narrow 상하한이 좁아져도 그 웨이브의 sparse일 때 상한 도달
  - 그 웨이브 narrow 상한 (sparse) → 출현 확률 상한
  - 그 웨이브 narrow 하한 (dense) → 1%
- 상한 20%는 Wave 80까지 유지 (이후 확장은 웨이브 순서의 각 섹션 참고)
- 보스는 적용 안 됨

### Wave 51 ~ 70: 방어막 데미지 감소 상승
- Wave 51 **-1.1**에서 매 웨이브 +0.1 → **Wave 70에 -3.0 도달 후 고정**
- Wave 130~145에서 추가 강화 (별도 섹션)

### Wave 61 ~ 70: 조밀도 상한 추가 강화 (maxNarrow 감소)
- 매 웨이브 maxNarrow를 -0.01씩 (10 웨이브 동안 누적 -0.10)
  - Wave 70: maxNarrow = 1.00 - 0.10 = 0.90
  - 효과: spawnInterval RNG 상한(가장 느슨한 분포)이 낮아져 평균 스폰 빈도 추가 상승
- Wave 71 ~ 170: narrow 0.30 ~ 0.90 고정 (다음 조밀도 변경은 Wave 171)

### Wave 71 ~: 적 수 고정
- 단계당 +1 → **0** (증가 중단, Wave 70의 115마리로 영구 고정 — 맵1은 Wave 79/124마리)

### Wave 71 ~ 90: EMP 적 등장
- 출현 확률: Wave 71 0.4%부터 매 웨이브 +0.4%, Wave 90에서 상한 8.0% 도달 (다른 맵 상한 4%의 2배)
- Wave 91+: 출현 확률 8.0% 고정
- 지상 타입, HP는 일반 지상의 **절반**
- 처치 시 반경 EMP_STUN_RANGE 내 타워가 있으면 그 자리에서 **EMP 장치**로 변환
- 보스에는 적용 안 됨

### Wave 81 ~ 90: 방어막 확률 상한 확장
- 매 웨이브 상한 +2% (10 웨이브 누적 +20%)
  - Wave 90: 상한 40% 도달
- Wave 91~100: 상한 40% 고정

### Wave 91 ~ 100: 수송 적 등장
- 출현 확률: Wave 91 0.4%부터 매 웨이브 +0.4%, Wave 100에서 상한 4.0% 도달
- Wave 101+: 출현 확률 4.0% 고정
- 공중 타입, 이동 속도는 일반 적의 **75%**
- 이동 중 최대 2회(경로 진행률 약 10%·20% 지점), 체력 40% 이상이면 체력 33%를 소모해 그 자리에 일반 적(체력 40%)을 투하
- 투하할 때마다 중앙의 빨간 원이 하나 사라짐 (남은 투하 횟수 표시)
- 보스에는 적용 안 됨

### Wave 100 ~: 이동 속도 고정
- Wave 100의 속도값 248로 영구 고정 (`50 + 99 × 2`)

### Wave 101 ~ 110: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +1%씩 추가 확장 (10 웨이브 동안 누적 +10%)
  - Wave 110: 상한 50% 도달
- Wave 111+: 방어막 상한 50% 고정

### Wave 130 ~ 145: 방어막 데미지 감소 강화
- 매 웨이브 방어막 적의 데미지 감소량 +0.1 (15 웨이브 동안 누적 +1.5)
  - Wave 131: -3.1 → Wave 145: -4.5
- Wave 146+: -4.5 고정

### Wave 151 ~ 160: 장벽 적 등장
- 출현 확률: Wave 151 0.4%부터 매 웨이브 +0.4%, Wave 160에서 상한 4.0% 도달
- Wave 161+: 출현 확률 4.0% 고정 (Wave 171~180 추가 상승은 맵1과 동일)
- 공중 타입, HP/속도는 일반 적과 동일
- 처치 시 그 자리에 장벽 생성 — 공중 공격 화력을 대신 받음 (지상 전용 공격은 통과)

### Wave 171 ~ 180: 조밀도 상하한 추가 강화 + 장벽 적 확률 상향
- 매 웨이브 minNarrow / maxNarrow 각각 -0.01 (10 웨이브 누적 -0.10)
  - Wave 180: minNarrow 0.20 / maxNarrow 0.80
- 매 웨이브 장벽 적 출현 확률 +0.4% (누적 +4.0%)
  - Wave 180: 8.0%
- Wave 181+: 모두 고정 (minNarrow 0.20 / maxNarrow 0.80 / 장벽 8.0%)

### Wave 181 ~ 190: 방어막 확률 상한 추가 확장
- 매 웨이브 상한 +3% (10 웨이브 누적 +30%)
  - Wave 181: 53% → Wave 190: 80%
- Wave 191+: 80% 고정

### Wave 50, 100, 150, 200: HP 슬로프 단계 상승
- 50웨이브 단위로 HP 증가량 +0.1
- Wave 50: 0.6 → **0.7**
- Wave 100: 0.7 → **0.8**
- Wave 150: 0.8 → **0.9**
- Wave 200+: 0.9 → **1.0** (최종 상한, 50웨이브당 HP +50)

## 보너스 메커니즘 (웨이브 종료 시)

- 모든 전직 가능 타워에 **+1 XP** (자동)
- 사거리 내에 배이스 / 비콘 / 데몬이 있으면 **+5 XP (5배 보너스, 고정값)**
- 다중 버프 소스 겹쳐도 5배 이상 누적되지 않음

## 난이도 곡선 의도

- **초반 (1~9)**: 해금 맵이라 학습보다는 실전 — 시작 스폰 간격 0.95초로 맵1보다 조밀하게 출발해 초반부터 배치 템포를 압박.
- **중반 (10~29)**: RNG 조밀도 + 공중 비중 증가로 다양성 확보. Tier 2 전직 압박.
- **후반 (30~50)**: 공중 HP 상승으로 대공 화력의 가치 증가. Tier 3 진입 시기.
- **종반 (50+)**: HP 슬로프 단계적 상승. 50웨이브 간격으로 규모 한 단계씩 확장 → 200까지 도달이 목표.
- **변곡점 (71~90)**: EMP 적 등장(맵2보다 90웨이브 앞당김, 상한 8%로 2배). 처치 지점 주변의 주력 딜러(웨이브 누적 데미지 최고)가 1초씩 멈춤 — HP가 절반이라 잡기는 쉽지만 경로 바로 옆 화력 집중 배치에 리스크를 부여. 처치 위치 관리·화력 분산 배치의 가치가 부각됨.
- **변곡점 (91~100)**: 수송 적 등장 (맵3의 151보다 60웨이브 앞당김). 느린 공중 유닛이 경로 위에 일반 적을 투하해 방어선 안쪽에 적이 갑자기 생김. 체력 40% 이상일 때 투하하므로 공중 조기 처치로 투하를 막는 것이 관건.
- **변곡점 (151~160)**: 장벽 적 등장 (맵1과 동일 시점). 공중 공격 화력이 장벽에 흡수됨 — 지상 전용 / areaSweep / 장벽 적 자체를 일점사로 처리하는 전략 필요.
- **재생 적 없음**: 맵4는 재생 적을 구성에서 제외 (회복을 뚫는 화력 검증 변수 없음).
- **안정구간 (200+)**: 모든 변수 상한. 적 수와 HP가 50웨이브당 일정량씩 증가하는 안정적 스케일.
