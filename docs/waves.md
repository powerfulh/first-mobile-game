# 웨이브 마일스톤

## 매 웨이브 변동 요소

| 항목 | 시작값 (Wave 1) | 변화 공식 |
|---|---|---|
| 적 수 | 8 | Wave 2~39: +2 / wave, Wave 40~79: +1 / wave, Wave 80+: 고정 |
| 지상 HP | 2 | `2 + floor((wave-1) × 0.6 + extraSlope)` (extraSlope는 50웨이브마다 +0.1) |
| 이동 속도 | 50 | +2 / wave (Wave 100+: 고정 248) |

## 단계별 메커니즘 변경점

### Wave 1 ~ 10: 점진적 가속
- 스폰 간격 1.2초 → 0.5초 (단계당 -0.08, Wave 10에서 캡 도달)
- 단순한 적 수 / HP / 속도 증가만

### Wave 5 ~: 공중 적 등장
- 출현 확률: `(wave - 4) × 2%`
- 공중 HP는 지상의 0.6배 (이 시점)
- 50% 상한 도달은 **Wave 29**

### Wave 11 ~: RNG 조밀도 시작
- 베이스 0.5초에 매 웨이브 RNG narrow factor 적용 → 0.2~0.5초 변동
- 임계 직후엔 변동폭이 좁고 점진적으로 넓어짐
- **Wave 11 → Wave 30**에 걸쳐 풀 RNG 범위(0.4~1.0 narrow)에 도달

### Wave 31 ~: 공중 HP 강화 시작
- 공중 HP 비율 0.6 → 1.0 점진 증가 (`+0.02/wave`)
- **Wave 50**에 지상과 동률(1.0) 도달

### Wave 40 ~: 적 수 증가량 완화
- 단계당 +2 → **+1**

### Wave 70 ~: 방어막 적 등장
- 출현 확률 범위: **1% ~ 20%** (Wave 70~80), 현재 웨이브 `spawnInterval` 기반 **반비례** 매핑
  - spawnInterval 0.5초 (sparse) → 상한
  - spawnInterval 0.2초 (dense) → 1%
- Wave 81~90: 상한이 점진적으로 20% → 40%로 확장 (단계당 +2%)
- Wave 91~100: 상한 40% 고정
- Wave 101~110: 상한이 매 웨이브 +1%씩 추가 확장 → 50% 도달 후 고정
- 방어막 적은 받는 데미지가 -3 감소
- 보스는 적용 안 됨

### Wave 80 ~: 적 수 고정
- 단계당 +1 → **0** (증가 중단, Wave 79의 124마리로 영구 고정)

### Wave 100 ~: 이동 속도 고정
- Wave 100의 속도값 248로 영구 고정 (`50 + 99 × 2`)

### Wave 101 ~ 110: 조밀도 하한 추가 강화 + 방어막 확률 상한 추가 확장
- 조밀도: 매 웨이브 minNarrow를 -0.01씩 감소 (10 웨이브 동안 누적 -0.10)
  - Wave 110: minNarrow = 0.40 - 0.10 = 0.30 (최소 spawnInterval 0.5 × 0.30 = 0.15s)
- 방어막 확률 상한: 매 웨이브 +1%씩 추가 확장 (10 웨이브 동안 누적 +10%)
  - Wave 110: 상한 50% 도달
- Wave 111+: 모두 고정 (minNarrow 0.30, 방어막 상한 50%)

### Wave 111 ~ 130: 재생 적 등장
- 출현 확률: Wave 111 0.2%부터 매 웨이브 +0.2%, Wave 130에서 상한 4.0% 도달
- Wave 131+: 출현 확률 4.0% 고정
- 적 결정 방식: 재생 확률을 먼저 굴리고 빠지면 공중 확률 (배타적). 방어막 modifier는 독립적으로 함께 적용 가능
- 지상 타입의 modifier (`e.type='ground'` + `e.regen` 플래그)
- 이동 속도: 일반의 50%
- HP: 일반 지상과 동일
- 자가 회복: HP < 100%일 때 `hpMax × 12% / 초` 회복 (사격이 멈춘 사이 다시 차오름)
- 보스에는 적용 안 됨

### Wave 121 ~ 130: 조밀도 상한 추가 강화 (maxNarrow 감소)
- 매 웨이브 maxNarrow를 -0.01씩 (10 웨이브 동안 누적 -0.10)
  - Wave 130: maxNarrow = 1.00 - 0.10 = 0.90
- Wave 131+: maxNarrow 0.90 고정
- 효과: spawnInterval RNG 상한(가장 느슨한 분포)이 낮아져 평균 스폰 빈도 추가 상승

### Wave 131 ~ 150: 방어막 데미지 감소 강화
- 매 웨이브 방어막 적의 데미지 감소량 +0.1 (20 웨이브 동안 누적 +2.0)
  - Wave 131: -3.1 → Wave 150: -5.0
- Wave 151+: -5.0 고정

### Wave 50, 100, 150, 200: HP 슬로프 단계 상승
- 50웨이브 단위로 HP 증가량 +0.1
- Wave 50: 0.6 → **0.7**
- Wave 100: 0.7 → **0.8**
- Wave 150: 0.8 → **0.9**
- Wave 200+: 0.9 → **1.0** (최종 상한, 50웨이브당 HP +50)

## 보너스 메커니즘 (웨이브 종료 시)

- 모든 전직 가능 타워에 **+1 XP** (자동)
- 사거리 내에 배이스 / 비콘 / 데몬이 있으면 **+5 XP (5배 보너스, 고정값)**
- 다중 버프 소스 겹쳐도 5배 이상 누적되지 않음

## 난이도 곡선 의도

- **초반 (1~9)**: 학습 단계. 가속도 낮고 변수 적음. 기본·벙커·스카웃 의사결정 학습.
- **중반 (10~29)**: RNG 조밀도 + 공중 비중 증가로 다양성 확보. Tier 2 전직 압박.
- **후반 (30~50)**: 공중 HP 상승으로 대공 화력의 가치 증가. Tier 3 진입 시기.
- **종반 (50+)**: HP 슬로프 단계적 상승. 50웨이브 간격으로 규모 한 단계씩 확장 → 200까지 도달이 목표.
- **변곡점 (111~130)**: 재생 적 등장. 단발 화력의 한계가 노출되어 광역·관통·마킹 카운터(4티어 합체 포함)의 가치가 부각됨.
- **안정구간 (200+)**: 모든 변수 상한. 적 수와 HP가 50웨이브당 일정량씩 증가하는 안정적 스케일.
